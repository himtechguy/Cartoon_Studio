# Cartoon Studio AI 🎬

A mobile-first cartoon creation studio.

## Features

- 🎨 AI image generation interface
- 🎥 AI video generation interface
- 👤 Character creator
- 🎬 Scene creator
- 📺 Episode builder
- 🖼️ Media gallery
- 💾 Local project saving
- 📱 Mobile friendly

## Files

- index.html
- style.css
- script.js

## AI Backend

The frontend expects:

GET /api/image?prompt=...

POST /api/video

Do NOT put a secret AI API key inside the public JavaScript.

The backend should securely connect to the AI provider.
